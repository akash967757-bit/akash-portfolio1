## PROMPT START

Build a **premium, modern, responsive personal portfolio website** for **Akash**, a Fresher Cloud Engineer (AWS / IT Infrastructure / Networking) and 2026 Electronics & Communication Engineering graduate based in Delhi, India.

### Design Direction (Dribbble-inspired, premium tech aesthetic)

- Dark-mode-first design with an optional light mode toggle
- Deep navy/charcoal background (#0A0E14 or similar) with a single vivid accent color (electric blue or cyan, e.g. #3B82F6 / #06B6D4) used sparingly for CTAs, links, and highlights
- Large, bold, confident hero typography (48–72px headline) paired with a clean sans-serif (Inter, Sora, or Space Grotesk)
- Generous white space, 12-column grid, card-based sections with soft borders/glassmorphism (subtle blur + translucent backgrounds)
- Subtle scroll-triggered fade/slide-in animations (Framer Motion or CSS reveal-on-scroll) — tasteful, not distracting
- Smooth scrolling between sections, sticky/floating nav with active-section highlight
- Abstract cloud/network-themed background accents: faint grid lines, node-and-connector graphics, or gradient blobs — avoid literal cloud clip-art
- Fully responsive: mobile-first, tested for phone/tablet/desktop breakpoints
- Fast-loading: optimized images, minimal external dependencies

### Site Structure & Content

**1. Hero Section**
- Headline: "Hi, I'm Akash — Aspiring Cloud Engineer"
- Subtitle: "ECE Graduate passionate about AWS Cloud, IT Infrastructure, Networking, Linux, and Cloud Technologies. I build practical cloud projects and continuously develop my skills to become a production-ready Cloud Engineer."
- CTA buttons: "View My Projects", "Download Resume", "Contact Me"
- Social links: LinkedIn, GitHub, Email
- Professional headshot placeholder (circular or rounded-square frame with subtle accent-color ring/glow)

**2. About Me**
- Position Akash as a 2026 ECE graduate starting his Cloud Engineering career
- Highlight his learning journey: AWS Cloud, Cloud Infrastructure, Networking, Linux Administration, IT Infrastructure, DevOps fundamentals, Infrastructure as Code, Automation
- Emphasize: hands-on learner who enjoys building, deploying, troubleshooting, and understanding real-world infrastructure
- Keep tone honest and entry-level — no exaggerated experience claims

**3. Technical Skills** (visual skill grid/pills, grouped by category)
- **Cloud:** AWS, EC2, S3, IAM, VPC, EBS, Route 53, Load Balancing, Auto Scaling, Cloud Fundamentals
- **Networking:** TCP/IP, LAN/WAN, Subnetting, DNS, DHCP, Routing, Switching, Network Troubleshooting
- **Operating Systems:** Linux, Ubuntu, Windows, Windows Server
- **DevOps & Tools:** Git, GitHub, Terraform, CI/CD Fundamentals, Virtualization, VMware, VirtualBox

**4. Projects** (card grid, each card includes: title, short description, tech stack tags, key responsibilities, GitHub link, live demo link if available)
1. **AWS VPC Infrastructure** — Custom VPC with subnets, route tables, Internet Gateway, security groups, EC2 instances
2. **AWS EC2 Web Server** — Deployed web server with configured networking, security groups, public access
3. **AWS S3 Static Website** — Static site hosted on S3 with proper access/hosting configuration
4. **AWS Load Balancing & Auto Scaling** — Scalable architecture using EC2, ALB, and Auto Scaling
5. **Terraform AWS Infrastructure** — AWS infrastructure provisioned via Infrastructure as Code

**5. Certifications**
- Display only genuinely earned certifications (e.g., AWS Certified Solutions Architate – Associate, CCNA, Linux/Networking certs) — leave section flexible/empty-state ready if none yet earned. Do not mark anything as completed unless confirmed.

**6. Education**
- Bachelor's in Electronics & Communication Engineering, Graduating 2026
- Optional field for CGPA/percentage if provided

**7. Experience / Internship**
- Fresher-appropriate section covering internships, cloud training, hands-on AWS labs, networking practice, infrastructure projects
- Use achievement-oriented bullets, not generic descriptions

**8. Career Objective**
"Seeking an entry-level opportunity in Cloud Engineering, AWS Infrastructure, IT Infrastructure, or Cloud Support where I can apply my knowledge of AWS, networking, Linux, and infrastructure technologies while continuing to grow as a cloud professional."

**9. Achievements**
- Small section for genuine academic, technical, college, or competition achievements only

**10. Contact**
- Heading: "Let's Build Something in the Cloud."
- Email, LinkedIn, GitHub, Location: Delhi, India
- Simple contact form: Name, Email, Message, Send Message button

### Technical & SEO Requirements
- Semantic, accessible HTML (proper heading hierarchy, alt text, ARIA labels where needed)
- SEO-optimized meta tags and headings using keywords: Cloud Engineer, AWS Cloud Engineer, AWS Fresher, Cloud Computing, AWS Infrastructure, IT Infrastructure, Networking, Linux, Terraform, DevOps, Cloud Support Engineer, AWS Solutions Architect, ECE Graduate, Cloud Engineer Delhi
- ATS/resume-friendly content structure
- Downloadable resume button (PDF link)
- Do not fabricate experience, certifications, or metrics — keep everything genuine and entry-level appropriate
